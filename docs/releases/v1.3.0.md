# Students IS v1.3.0

The biggest update so far: a new look for the assistant and the review questions, an installable app, and a more accurate analytics dashboard for admins.

## What's new

**Assistant**
- Semi-glass chat panel in light and dark mode, with a smaller, redesigned chat button.

**Review questions**
- Modern card layout with a score ring, a progress bar, lettered options (A–D / أ–د) and clear correct / wrong states. Same logic as before: shuffled options, score and retry.

**Installable app (PWA)**
- Web App Manifest, app icons and a safe service worker (same-origin static assets only; Supabase traffic is never intercepted).
- Friendly offline page when there is no connection.

**Admin analytics**
- Visits, files opened and active students, each compared with the previous period.
- Daily activity chart, peak hours, top subjects and top files, CSV export.
- Admin activity is excluded by default so testing does not skew the numbers; days follow the admin's local time.

**Project**
- Professional README in English and Arabic, contributing guide, security policy, issue and pull request templates, Dependabot.

## Upgrade notes
- Run `supabase/stats_v2.sql` once in the Supabase SQL Editor to enable the new analytics (it only adds functions and is safe to re-run). Without it the dashboard falls back to the basic statistics.
- No breaking changes.
